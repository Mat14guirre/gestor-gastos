# 💰 App de Gastos Personales

Aplicación web para la **gestión de gastos personales en tiempo real**, sincronizada con Firebase.  
Permite a dos usuarios (ej: pareja) llevar un registro compartido de ingresos y egresos desde cualquier dispositivo.

---

## 📸 Demo

👉 [Enlace al deploy](https://tablero-de-gasto.netlify.app/) *(si lo tenés en Vercel, Netlify o Firebase Hosting)*  

---

## 🛠️ Tecnologías utilizadas

- ⚛️ React  
- 🔥 Firebase (Auth + Firestore)  
- 🧭 React Router  
- 🎨 TailwindCSS  

---

## ✨ Características principales

- 🔐 **Login con Google**.  
- 🔄 **Sincronización en tiempo real** de gastos entre varios dispositivos.  
- ➕ **Agregar gastos e ingresos** con fecha, descripción y monto.  
- 🗑️ **Eliminar registros** fácilmente.  
- 📊 **Resumen visual** del estado de gastos e ingresos.  
- 📱 **Responsive**: usable desde móvil y desktop.
